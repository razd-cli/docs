Выпущена стабильная версия **v1.x** — результат большой работы по переработке архитектуры. Версия **1.6** стала заметно более стабилизированной и готовой к продакшену.

## Переход на Go

Razd переписан на **Go**. Это не просто смена языка — изменилась сама архитектура.

Раньше `razd` был обёрткой, которая требовала установленного `task` (Taskfile) в системе. Это создавало лишний барьер: «скачай razd, а, ой, ещё task установи».

Теперь движок **Go-Task (v3)** импортируется как библиотека прямо в код `razd`. Внутри razd живёт Taskfile — пользователю нужен только один бинарник, всё работает из коробки.

Подробности перехода описаны в [issue #38](https://github.com/razd-cli/razd/issues/38).

## Снижена зависимость от Mise

Снижена зависимость от **Mise**. Теперь для управления инструментами можно использовать и **Devbox**, который особенно удачен для PHP-проектов — с версионированными пакетами и расширениями.

Выбор провайдера задаётся в `Razdfile.yml`:

```yaml
dependencies:
  using: "devbox"   # или "mise"
  ensure:
    - "php@8.4.15"
```

## Обновлён стандарт Razdfile.yml

Вместе с новой архитектурой обновлён и стандарт конфигурации — `Razdfile.yml` версии `"1"`. Он объединяет управление зависимостями и задачами в одном файле.

```yaml
version: "1"

dependencies:
  using: "mise"     # или "devbox"
  ensure:
    - "node@22"
    - "task@latest"

tasks:
  default:
    desc: Set up project
    cmds:
      - task: install
      - task: dev
```

Ключевые изменения:

- **`version: "1"`** — явная версия формата
- **`dependencies.using`** — выбор провайдера: `mise` или `devbox`
- **`dependencies.ensure`** — инструменты в формате `tool@version`
- **`tasks`** — стандарт Taskfile, теперь исполняется нативно внутри razd

## Что это даёт

- **Один бинарник** — без внешних зависимостей
- **Нативный Taskfile** — движок Go-Task (v3) встроен в razd как библиотека: задачи исполняются внутри процесса, без спавна внешнего бинарника `task`. Это даёт прямой доступ к API раннера, стриминг вывода и контексты выполнения
- **Гибкий выбор провайдера** — mise или devbox под ваш стек

Попробуйте сами:

```bash
razd up https://github.com/razd-cli/razd-nodejs-example
```
